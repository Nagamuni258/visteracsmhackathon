# RoadBump Mobile & System Screenshots

This directory contains device screen captures, UI mockups, and validation test recordings captured during the development and testing of the RoadBump mobile application.

## Catalog of Screenshots

### HUD & Live Telemetry
- `phone_active.png` – Active HUD view showing live telemetry, speed, and hazard monitor.
- `phone_hud_live_location.png` – HUD screen tracking real-time GPS location coordinates.
- `phone_hud_simulating.png` – HUD in sensor-simulation drive mode.
- `phone_hud_approaching_countdown.png` – Approaching hazard countdown audio/visual alarm.
- `phone_hud_view_on_map.png` – View approaching hazard directly on the map.

### Live Map & Community Verification
- `phone_screen_map.png` – Main interactive hazard map with clustered markers.
- `phone_screen_map_clicked.png` – Selecting a hazard pin on the live map.
- `phone_screen_map_dropped.png` – Dropping a new hazard pin at user location.
- `phone_screen_map_verified.png` – Community-verified hazard pin with confirmation badges.
- `phone_screen_map_view.png` – Fullscreen hazard map display.
- `phone_approved_map_view.png` – Map displaying admin-approved road hazards.
- `phone_roadbump_map_final.png` – Final map view with synced hazard pins.

### Pedestrian Photo-Report & Admin Triage
- `phone_report_screen.png` – Pedestrian camera reporting screen.
- `phone_report_screen_approve.png` – Report submission and approval confirmation dialog.
- `phone_report_scrolled.png` – Extended report form with severity scoring and description.
- `phone_scrolled_report.png` – Additional report view details.
- `phone_camera_test1.png` – CameraX live stream test capture 1.
- `phone_camera_test2.png` – CameraX live stream test capture 2.
